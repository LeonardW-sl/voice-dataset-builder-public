# 项目结构

> 本页列文件入口，不代表质量已通过验收。当前问题与改进顺序见 [README](../README.md)。

```
voice-dataset-builder-public/
├── README.md
├── requirements.txt
├── config/default.yaml      部分切分/筛选设置，不包含全部模型运行参数
├── scripts/
│   ├── common.py            配置加载、区间合并、削波统计
│   ├── 00_decode.py         mp3 -> 16k mono wav
│   ├── 01_measure.py        单段自检（RMS/削波/说话占比）
│   ├── 02_aed.py            FireRedVAD 三标签切分
│   ├── 03_sep_score.py      Demucs 算 V2A 分贝比（只评分）
│   ├── 04_embed.py          CAM++ 声纹；支持 --ref-wav
│   ├── 05_asr_whisper.py    本机 CPU 基线识别
│   ├── 06_asr_firered.py    服务器 FireRedASR2-AED 适配器
│   ├── 07_export.py         应用全部闸门，从原始 mp3 导出
│   ├── 09_review.py         生成人工审核清单
│   └── run_file.sh          单文件全流程编排（可断点续跑）
├── tools/tune.py            打分分布直方图，辅助定阈值
├── tests/test_gates.py      闸门逻辑单测（pytest）
└── docs/
    ├── 公开前检查.md        公开版本范围与检查边界
    ├── 队友接手.md          问题证据与修复验收顺序
    ├── 验收流程.md          人工验收口径
    └── 已知问题.md          踩过的坑
```

## 中间产物

`out/<run>/work/<stem>/` 下保留中间结果。入口目前只按文件存在与否跳过步骤；修改设置、识别模型或参考声音时，须使用新输出目录或明确重新计算相关步骤。

| 文件 | 步骤 |
|---|---|
| `a.wav` | 解码 |
| `a.aed.json` | 切分 |
| `a.emb.json` | 声纹 |
| `a.sep.json` | V2A 打分（可选） |
| `a.asr.json` | 识别 |

## 换识别引擎

设置 `ASR_SCRIPT=scripts/06_asr_firered.py`（选择服务器转写脚本）可以切换入口，但需要另装上游环境、核对参数和输出，并使用新的输出目录；该适配尚未完成服务器端验收。

两个引擎的 `confidence`（识别分数）虽然都落在 0–1 范围，**不代表它们具有相同的可信程度**。当前本机脚本将平均对数分数取指数，并没有通过人工标注校准；换引擎后必须重新评估筛选线。
